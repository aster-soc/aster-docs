# Binary Installation

Aster is packaged into JAR binaries that can be run on any device with a Java runtime.

## Installing Dependencies

```sh
# on Debian
sudo apt install openjdk-21-jre

# on Arch
sudo pacman -Sy jre21-openjdk
```

After installing, run `java --version` to ensure the correct Java version is being default.
